# Fact Noggin public site

Public pages for Fact Noggin, served by GitHub Pages at https://semzzzz-stack.github.io/Fact-noggin-public/

- `index.html`: about Fact Noggin and the Fact Noggin Poster tool
- `terms.html`, `privacy.html`: Terms of Service and Privacy Policy of the TikTok app
- `callback.html`: TikTok login redirect page (shows the connection code to copy)
- TikTok URL-prefix verification file goes at the root.

Privacy Policy

Last updated: November 1, 2026

Fact Noggin Poster ("the app") posts Fact Noggin's own videos to the Fact Noggin TikTok account. It is used only by the owner of that account (contact: factsnoggin@gmail.com).

What data the app receives from TikTok

  • An access token and refresh token, so it can post videos to the connected account.
  • The account's open ID, nickname and posting settings (allowed privacy levels, maximum video length), read with the user.info.basic and Content Posting API scopes so each post respects them.

What the app does not collect

  • No data from any other TikTok user, no followers, messages, contacts, location, or analytics.
  • No cookies or tracking; the app has no public website or user interface.

How data is stored and used

  • Tokens are used only to upload and publish the account owner's videos.
  • The refresh token is stored encrypted (AES-256) in the operator's private GitHub repository and is never shared, sold or used for advertising.
  • A log of posted videos (episode name, TikTok publish ID, status and time) is kept in the same private repository.

Deleting data

Disconnect the app in TikTok (Settings and privacy → Security and permissions → Apps and services), or email factsnoggin@gmail.com; stored tokens are deleted within 7 days.
